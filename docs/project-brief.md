# Project Brief: Agentic-Senior-Core Site

## Scope And Objective

This project implements the public landing page for **Agentic-Senior-Core**, the npm package at `E:\Project\Agentic-Senior-Core`.

The current source repo is a v5 universal plugin system. The site should:

1. Explain the v5 product surface: always-on `AGENTS.md`, plugin-tier hosts, instruction-tier adapters, skills, commands, `ascx`, and MCP.
2. Provide copyable setup commands grounded in the README: global npm install, Codex plugin install, adapter generation, and `asc status`.
3. Show compact CLI samples for `asc status` and `ascx`.
4. Link to the source repo docs for agent portability and plugin architecture.

## Target Audience

Developers who use AI coding agents across terminal tools and IDEs, and want one small rule package that nudges agents toward staff-engineer habits without large project scaffolding.

## Technical Parameters

- Framework stack: React 19, TypeScript 6, Vite 8, Motion, Lucide React.
- Design paradigm: restrained neo-brutal product sheet with strong borders, flat surfaces, copyable commands, and a visible product mark.
- Styling: CSS custom properties, responsive grid, no horizontal scroll.
- Accessibility floor: WCAG 2.2 AA, keyboard-accessible controls, visible focus states, and reduced-motion support.
