# Project Brief: Agentic-Senior-Core Site

## Scope & Objective
This project implements the public, high-fidelity promotional landing page for **Agentic-Senior-Core** (the production-grade rules engine for AI coding agents). 

The goal of the site is to:
1.  **Introduce the Rules Engine**: Explain the value of guiding AI agents using staff-engineer architectural invariants, rather than leaving them to default behavior.
2.  **Display CLI Playback Telemetry**: Visually demonstrate how the ASCX wrappers intercept and compress verbose shell output to save up to 80% token overhead.
3.  **Provide Boot Commands**: Deliver clear, copyable shell inputs for standard init, VS Code MCP configuration, and system upgrades.
4.  **Register the 21 Rulesets**: Offer an interactive registry where developers can browse Layer 1-9 rulesets (Architecture, Security, Database, Performance) and view code-invariant schematics.

## Target Audience
Senior software architects, tech leads, and principal engineers seeking robust compliance frameworks and token economy in their automated workflows.

## Technical Parameters
*   **Framework Stack**: React 19, TypeScript 6, Vite 8, Framer Motion 12, Lucide React icons.
*   **Design Paradigm**: Modular Audio-Chassis Console (Teenage Engineering & Eurorack inspired).
*   **Styling**: Pure CSS custom properties styled with repeating gradients and fluid Clamp scaling.
*   **Accessibility Floor**: WCAG 2.2 AA (rigid high-contrast ratios, complete keyboard access, and reduced-motion stylesheet fallbacks).
